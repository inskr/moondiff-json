# AI 使用说明

本作品开发使用 Codex AI 编程助手。用户提供规格、执行计划、约束和阶段授权；助手协助核对
实际依赖源码、准备固定工具链、编写 MoonBit 核心、Node CLI、静态网页、测试、CI、基准和材料，
通过本机命令验证。各阶段由当前代理串行实施与审查；没有将代理自述当作测试证据，也未声称
尚未进行的人工审核。开发遵循关键失败测试、最小实现与真实检查。

docs/validation 保留实际失败与修复，包括依赖/导出、CLI/Worker 行为以及任务八测试夹具错误。
固定 seed 属性测试用故意“全部相等”的适配器证明断言能发现精度错误，适配器不进入产品。
环境版本、原始基准样本和报告字节校验由真实运行产生，未由 AI 估算。

视频由助手用 Playwright 驱动真实 Chrome 页面录制，中文字幕是录制会话说明层，非产品界面；
无配音、无倍速、无生成画面替代软件运行。脚本和黄金下载校验可复现。运行时没有 AI 服务、
LLM 接口、密钥、遥测或用户 JSON 上传；AI 仅用于开发。

许可证文本原样来自安装的上游依赖，见 THIRD_PARTY_NOTICES.md。项目暂用 local/moondiff-json，
未指定公开参赛者 namespace，未发布或报名。正式提交前由参赛者核对当届 AI 披露与资格要求；
本说明不声称已满足未核对的赛事条款。
